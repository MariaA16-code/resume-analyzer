
# Resume Analyzer

## Overview
Built this to practice working with PDF parsing and keyword extraction 
using NLP techniques.

## Tech Stack
- Python, Flask
- PyPDF2, spaCy
- HTML, CSS, JavaScript

## Features
- Upload PDF resume
- Keyword extraction and skill detection

## Run Locally
```bash
pip install -r requirements.txt
python app.py
```
